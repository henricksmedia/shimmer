Two versions of the same music, both playing at once. The button swaps which one reaches your ears — same instant, no gap, no restart. Levels are matched before anything is written, so you are hearing the difference and not the volume. Developer tooling; not part of the app.

Everything is matched to the quietest arm, so nothing is ever turned up and nothing clips. The louder file always wins an unmatched comparison — that is how this project got its first wrong answer.

Keys

space play / pause · S swap · R what was removed · L loop the last 4 seconds · 0 back to the start

About "what was removed": it tells you whether the thing taken out was noise or music. It cannot tell you whether too much was taken. Removed air sounds like shhh on its own and never like music, so a track can lose real openness while the removed part still sounds like nothing. Judge how much by comparing A and B, not by listening to the difference.
